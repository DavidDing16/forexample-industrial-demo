Preguntas sobre la aplicación

¿Cómo elijo un proceso?

Describa el material, el proceso de corte, la geometría, el estado de las rebabas y el acabado deseado. Valide el proceso con pruebas de muestras antes de comprar.

¿Son precios firmes o configuraciones garantizadas?

No. Solo se muestran suplementos ficticios de opciones. La disponibilidad, la compatibilidad, las condiciones de entrega y el precio final requieren confirmación del proveedor.

¿Puedo enviar una consulta real aquí?

Esta demo de GitHub Pages no envía consultas. Un sitio comercial requiere un backend independiente, revisión de privacidad y datos reales de contacto.
